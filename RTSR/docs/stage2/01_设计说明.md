# 阶段二设计说明（索引）

系统级仿真器的**完整设计文档在代码目录里**：[`../../sl/README.md`](../../sl/README.md)。

那份文档包含：

| 章节 | 内容 |
|---|---|
| §1 | 为什么必须另写（ns-3 跑 1000 s 需 175 天/点）|
| §2 | **十个"论文没写"的假设**，每项给保守档 / 理想档两个取值 |
| §3 | 两档标定目标（保守 190 Mbps、理想 330–400）|
| §4 | 物理与场景参数（与阶段一逐项一致）|
| §5 | 模块划分与每个 TTI 的执行顺序 |
| §6 | 业务模型（含模型质量 q 的定义）|
| §7–§8 | 输出格式、7 条验证标准 |
| §9–§11 | 里程碑与实测记录（M1/M2/M3/M5/M6，含 10 轮迭代的错误与修法）|

模块清单：

| 文件 | 职责 |
|---|---|
| `config.py` | 场景参数 + 两档假设（唯一参数来源）|
| `topology.py` | 六边形布局、外圈、UE 撒点、移动 |
| `channel.py` | UMa 路损 / 阴影 / 穿透 / 波束 / 衰落 → SINR |
| `link.py` | SINR → 频谱效率 → TB 字节 |
| `scheduler.py` | TDMA 轮转（保守）/ OFDMA 比例公平（理想）|
| `traffic.py` | 60 FPS 帧源 + 模型流 + 10 ms PDB |
| `metrics.py` | 每 UE FSR → 满意率 |
| `check_m1/m2/m3/m5.py` | 四个自检脚本（分别对标 ns-3 与论文）|
| `run_point.py` / `m6_wrap.py` | M6 单点运行器 / 汇总出图 |
