## 两句话总结

- **阶段一**（ns-3，6 s）：趋势复现，拐点左移；根因是 **TDMA 调度器只用 1/3 频谱**，容量 190 Mbps。
- **阶段二**（系统级，1000 s × 3 种子）：换成 OFDMA 后容量 **399 Mbps**，23 UE/cell 处
  传统 39.3% vs RTSR 72.0%（**+32.7 pp**），复现论文核心结论。
