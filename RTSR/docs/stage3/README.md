## 不做什么

- 不在 ns-3 里强行开 OFDMA（模拟波束约束，物理不可行，见阶段一偏差 #11）
- 不通过放宽 PDB 判据来"凑" FSR（会削弱结论）

> ⚠️ **TDD 口径**：系统级仿真器未建模 TDD 时隙结构，所有满意率与承载吞吐按「全下行」口径。两种口径的对照见 [`03_总结.md`](03_总结.md) 第 12 节。
